# Depo başlangıç notu

Mevcut GitHub deposunun bu MVP gönderilmeden önceki ilk commit'inde README içeriği şu iki satırdan oluşuyordu:

```text
# OpenCAD-Pro
v2.2.0
```

Bu ilk commit, merge ile korunmuştur. Ancak kaynak kodu, release tag'i veya derleme çıktısı içermediğinden `v2.2.0` etiketi bu depoda doğrulanmış bir yazılım sürümü olarak ele alınmamıştır. Bu nedenle eklenen derlenebilir prototipin sürümü `0.1.0` olarak tanımlanmıştır.
